# Python 后端课程大纲（合成演示材料）

这是虚构课程资料，用于项目演示，不代表真实学校的教学安排。

## 第一阶段：Python 与 HTTP

第一周学习函数、异常、类型注解和虚拟环境。第二周学习 HTTP 方法、状态码、请求头及 JSON，使用 FastAPI 创建参数验证接口。作业要求实现用户注册、密码哈希和登录。

## 第二阶段：数据库

第三周学习 PostgreSQL 表结构、外键和唯一约束。第四周学习 SQLAlchemy 事务及 Alembic 数据库迁移。课程要求用数据库约束保障一致性，不仅依靠应用层判断。

## 第三阶段：后台任务

第五周学习 Redis、Celery 和任务重试。重复任务执行必须具有幂等性，不能重复生成文档分块。CPU 密集型 PDF 解析应交给 Worker，不应阻塞 Web 服务事件循环。

## 第四阶段：AI 应用

第六周学习文本切分、向量检索和 RAG。第七周完成流式问答和来源引用，第八周完成评测与部署。最终考核包括功能演示、失败场景演示、技术答辩和真实测试报告。
