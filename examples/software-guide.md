# 星河文档服务操作手册（合成演示材料）

本文为本项目自编的虚构软件说明，用于检索和问答演示，不代表任何真实公司的制度。

## 数据库连接

星河文档服务通过 DATABASE_URL 环境变量设置数据库连接地址。开发环境使用 SQLite，团队部署使用 PostgreSQL。修改连接地址后需要重启 API 和后台 Worker。数据库密码不应写进源代码或提交到 Git。

## 上传文件

文档上传支持 UTF-8 编码的 TXT、Markdown 和带文字层的 PDF。单个文件最大为 10 MiB。扫描版 PDF 需要预先通过 OCR 转为包含文字层的文件。本版本不提供 OCR 服务。

## 后台任务

上传接口返回文档 ID 和任务 ID。用户通过任务 ID 查询处理进度，文档完成解析和索引后才能参与问答。临时网络故障可以重试，损坏的 PDF 需要修复后重新提交。

## 数据恢复

团队部署每天凌晨 02:00 执行数据库备份，并保留最近 7 天的备份文件。恢复演练必须同时检查数据库元数据和原始文件。这是虚构产品的操作约定；本示例仓库没有实现自动备份任务。

## 权限

每个用户只能访问自己创建的知识库。删除文档后，该文档立即停止参与检索。后台文件清理完成时间不影响权限判断和检索可见性。
